## Design system: 1001 Órbita

A identidade visual segue a **1001 Órbita**, o design system da 1001 Negócios Imobiliários feito no Claude Design. Ele também é usado no INAD e no Financeiro.

- **Original (Claude Design):** https://claude.ai/artifact/XMKotRqCPMmp9L3TSPgwgU. Comece pelo manual (README), que trata de voz, cor, tipografia, logo e componentes.
- Os arquivos não estão neste repositório. A Órbita, as logos e a identidade visual são da 1001 Negócios Imobiliários, com todos os direitos reservados, e este repositório é público.
